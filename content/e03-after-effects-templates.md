## Featured

### EarnEdits ✅
**[earnedits.com](https://earnedits.com/)**

A library of **open, editable After Effects project files (.aep) rebuilt from high-performing social and SaaS edits**. The pitch is learning by taking apart real timelines: compositions, transitions and layer structure, not drag-and-drop placeholders.

| | |
|---|---|
| **What you get** | Full .aep per project, organised comps, editable UI elements |
| **Styles** | Viral edits, SaaS UI explainers (Google Drive, Slack, Opal, Lovable-style AI builders, "YouTube 2.0" concepts), motion graphics |
| **Pricing** | Single projects about **$14.99 to $17.99**; **all projects for $27/month** |
| **Free** | [Free project to try](https://earnedits.com/free-after-effects-project-files/), no login needed |
| **Specs seen** | AE CC 2025+, 1920×1080 on recent uploads |
| **Watch out for** | Required fonts and effects aren't bundled; AE flags anything missing when you open the file |
| **Best for** | Editors who already know AE and want to learn pro structure |

Useful pages: [Shop](https://earnedits.com/shop/) · [What AE project files are](https://earnedits.com/after-effects-project-files/) · [Motion graphics project files](https://earnedits.com/after-effects-motion-graphics-project-files/)

## How to pick and use project files

| Goal | Pick |
|---|---|
| Learn how pro edits are built | EarnEdits, Motion with Nas, Designffective |
| Most projects per dollar | Madbax Editor Zone |
| Reusable pieces you drop in from a panel | aepmotion, Spotlight FX, What? Studio |
| SaaS launch video fast | SaaSor, Dream Chaser kit, then one single-project file from list B |

**Before you buy**
1. **Check the AE version.** Files saved in a newer AE won't open in an older one.
2. **Check fonts and plugins.** Most stores don't bundle fonts. "No plugins" files are safest.
3. **Check the licence.** Many single-project sellers say *educational use only* or *no resale or redistribution*. Confirm client-work rights before using one commercially.

**After you open one**
- Use **File → Dependencies → Collect Files** to keep a clean, self-contained copy.
- Swap AE 27's new **3D materials** in for flat fills to make a template your own ([E02](e02-after-effects-27-updates.md)).
- Let **[Atom](e01-atom-guide.md)** do the rebranding pass: *"Change every colour to our brand palette and expose them on one control layer."*
